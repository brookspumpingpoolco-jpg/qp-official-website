Use this page to test the invoice viewer before deploying to Webflow.

⚠️ Instructions:
1. Send a test invoice from the invoice maker
2. Copy the share link from the success message
3. Replace "YOUR-INVOICE-ID" in the URL below
4. Click "Test in iframe" or "Open Direct"

Test URL:

https://aesthetic-kataifi-88ba27.netlify.app/InvoiceEstimateViewer.html?id=Invoice-60669512-8825&token=7b76c96a-c2ad-4727-971c-f1bf49431c22
Open Direct (New Tab)

Troubleshooting:

  • If you see "No invoice ID provided" → The URL is missing ?id=Invoice-xxx
  • If you see "Loading invoice..." forever → Check browser console (F12) for errors
  • If you see "Failed to load invoice" → The invoice ID might be wrong or not exist
  • Press F12 to open browser console and see debug logs

For Webflow Embed:

Once this works, use this code in Webflow:

<div style="width: 100%; min-height: 100vh;">
  <iframe 
    src="https://aesthetic-kataifi-88ba27.netlify.app/InvoiceEstimateViewer.html" 
    width="100%" 
    height="100%" 
    frameborder="0"
    style="min-height: 100vh; border: none;">
  </iframe>
</div>

<script>
  const iframe = document.querySelector('iframe');
  const urlParams = window.location.search;
  if (urlParams && iframe) {
    iframe.src = iframe.src + urlParams;
  }
</script>
